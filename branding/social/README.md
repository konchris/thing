# Social Preview

This directory holds the GitHub social preview image for the THING repository.

## Required File

```text
branding/social/thing-github-social-preview-1280x640.png
```

| Property | Required Value |
| --- | --- |
| Dimensions | 1280 × 640 px |
| File size | < 1 MB |
| Format | PNG |

## Usage

Upload this file under **GitHub repository settings → Social preview**.

The image should use the THING visual identity: restrained palette, `ÞING` title treatment, no hype styling.
