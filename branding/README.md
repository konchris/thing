# THING Branding

This directory contains the visual and documentation identity source assets for THING.

## Structure

| Directory | Purpose |
| --- | --- |
| `logo/` | Primary logo and symbol marks — horizontal and symbol, light and dark variants |
| `favicon/` | Favicon and app icon set — SVG and PNG at standard sizes |
| `colors/` | Color tokens, CSS custom properties, and palette documentation |
| `typography/` | Typography guidance and font stack recommendations |
| `readme/` | README header SVGs and header system documentation |
| `diagrams/` | Diagram theme and visual tokens for D2 diagrams |
| `social/` | GitHub social preview and share image assets |

## Usage Principles

- Use branding to create coherence, not decoration.
- Prefer restrained, monochrome-compatible assets.
- Diagrams and documentation structure are part of the brand.
- Color should encode structure, not mood.
- Avoid AI hype visuals, cyberpunk styling, fake historical aesthetics, and generic startup language.
