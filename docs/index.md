# THING Documentation

THING is a systems engineering workflow library for AI coding agents.

It guides an agent through a full SE lifecycle — stakeholder elicitation,
Concept of Operations, non-functional requirements, Set-Based Design,
requirements derivation, multi-view architecture, interface control, V&V
planning, requirements traceability, and risk management — producing
version-controlled Markdown artifacts alongside the code.
